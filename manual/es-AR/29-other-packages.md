# Otros paquetes

Entre el repositorio oficial y el Arch User Repository (AUR), Arch tiene una riqueza increíble de paquetes para casi cualquier tipo de software.

Y usar cualquiera de los dos no podría ser más fácil. Instalás un paquete nuevo de Arch yendo a _Instalar > Paquete_ en el menú de Omarchy (`Super + Space`) y escribiendo el paquete que querés. La lista de todos los paquetes se filtra sola con búsqueda difusa. (También lo podés hacer a mano con `omarchy pkg add [package]` en la terminal).

Con el AUR es igual, solo que usás _Instalar > AUR_. Acordate de que el equipo de Arch no revisa el AUR. Es como RubyGems o npm. Cualquiera puede subir cosas.

Si querés desinstalar un paquete, podés usar _Eliminar > Paquete_ desde el menú de Omarchy. Se borran el paquete, sus archivos de configuración y sus dependencias. (También lo podés hacer a mano con `omarchy pkg drop [package]`).
