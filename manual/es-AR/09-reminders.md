# Recordatorios

Omarchy trae una forma integrada de crear recordatorios simples con una cuenta regresiva y un mensaje. Creás uno con `Super + Ctrl + R`, ves todos los que creaste con `Super + Ctrl + Alt + R` y los borrás todos con `Super + Ctrl + Shift + R`. Todo eso también está en _Acciones > Recordatorio_. Y además podés usar la CLI con `omarchy reminder 7 'Tea ready'`.
