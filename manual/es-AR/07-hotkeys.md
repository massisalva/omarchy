# Atajos de teclado

Podés ver todos los atajos principales con `Super + K` (los de Tmux con `Super + Alt + K` y los de Herdr con `Super + Ctrl + K`).

## Navegación

| Atajo                  | Función              |
| ----------------------- | --------------------- |
| `Super + Space`           | Menú de Omarchy (apps y todo lo demás)    |
| `Super + Alt + Space` | Grilla de apps |
| `Super + Escape` | Menú del sistema (suspender, reiniciar, etc.)  |
| `Super + Ctrl + L` | Bloquear la computadora |
| `Super + W` o `Super + Q` | Cerrar ventana             |
| `Ctrl + Alt + Del` | Cerrar todas las ventanas |
| `Super + T`               | Pasar la ventana de mosaico a flotante y viceversa             |
| `Super + J` | Cambiar la orientación de la ventana (horizontal/vertical) |
| `Super + O`               | Despegar la ventana: flotante y fija en todos los espacios |
| `Super + L`               | Alternar entre las distribuciones dwindle, desplazamiento y flotante |
| `Super + Alt + L`         | Alternar las distribuciones en sentido inverso |
| `Super + P`               | Alternar el estilo pseudo de la ventana (tamaño natural vs. estirada) |
| `Super + F`                 | Pantalla completa              |
| `Super + Alt + F`                 | Todo el ancho              |
| `Super + Ctrl + F`                 | Pantalla completa dentro de la ventana              |
| `Super + 1/2/3/4`         | Ir a un espacio de trabajo del monitor con foco |
| `Super + Tab` | Ir al siguiente espacio de trabajo del monitor con foco |
| `Super + Shift + Tab` | Ir al espacio de trabajo anterior del monitor con foco |
| `Super + Ctrl + Tab` | Volver al último espacio de trabajo usado en el monitor con foco |
| `Super + Shift + 1/2/3/4` | Mandar la ventana a un espacio de trabajo del monitor con foco |
| `Super + Shift + Alt + 1/2/3/4` | Mandar la ventana a un espacio de trabajo del monitor con foco sin seguirla |
| `Super + S` / `Super + Grave` | Mostrar/ocultar el scratchpad |
| `Super + Alt + S` / `Super + Shift + Grave` | Mandar la ventana al scratchpad |
| `Super + Shift + Ctrl + Arrows` | Mandar la ventana al monitor en esa dirección |
| `Super + Shift + Alt + Arrows` | Mandar el espacio de trabajo al monitor en esa dirección |
| `Super + Arrow`  | Pasar el foco a la ventana en la dirección de la flecha, cruzando al monitor de ese lado en el borde de la pantalla |
| `Super + Shift + Arrow`  | Intercambiar la ventana con otra en la dirección de la flecha, incluso una del monitor de ese lado |
| `Super + Minus` | Agrandar la ventana hacia la izquierda |
| `Super + Equal` | Achicar la ventana hacia la izquierda |
| `Super + Shift + Minus` | Achicar la ventana hacia arriba |
| `Super + Shift + Equal` | Agrandar la ventana hacia abajo |
| `Super + Alt + Minus/Equal` | El mismo cambio de tamaño, en pasos más chicos |
| `Super + Ctrl + Minus/Equal` | El mismo cambio de tamaño, en pasos más grandes |
| `Super + Alt + Home` | Guardar el ancho de la ventana |
| `Super + Home` | Recuperar el ancho guardado |
| `Super + Left Mouse` | Arrastrar la ventana |
| `Super + Right Mouse` | Cambiar el tamaño de la ventana |
| `Super + Scroll Wheel` | Recorrer los espacios de trabajo del monitor con foco |
| `Super + G`               | Agrupar/desagrupar ventanas      |
| `Super + Alt + G`               | Sacar la ventana del grupo      |
| `Super + Alt + Tab`               | Pasar a la siguiente ventana del grupo      |
| `Super + Alt + Shift + Tab`               | Pasar a la ventana anterior del grupo      |
| `Super + Alt + Scroll Wheel` | Recorrer las ventanas del grupo |
| `Super + Alt + 1/2/3/4/5`               | Ir a una ventana específica del grupo      |
| `Super + Alt + Arrow`  | Meter la ventana en el grupo en la dirección de la flecha, incluso uno del monitor de ese lado |
| `Super + Ctrl + Left/Right`  | Moverse entre las ventanas de un grupo en mosaico |
| `Super + Ctrl + Z` | Hacer zoom en la pantalla (repetir para acercar más) |
| `Super + Ctrl + Alt + Z` | Sacar todo el zoom de la pantalla |
| `Super + /` | Avanzar por las opciones de escala del monitor |
| `Super + Alt + /` | Retroceder por las opciones de escala del monitor |
| `Alt + Tab` | Recorrer hacia adelante las ventanas del espacio de trabajo activo |
| `Alt + Shift + Tab` | Recorrer hacia atrás las ventanas del espacio de trabajo activo |
| `Ctrl + Alt + Tab`| Pasar el foco al siguiente monitor |
| `Ctrl + Alt + Shift + Tab`| Pasar el foco al monitor anterior |

## Portapapeles universal

| Atajo                  | Función              |
| ----------------------- | --------------------- |
| `Super + C`           | Copiar    |
| `Super + X`           | Cortar (no en la terminal)    |
| `Super + V`           | Pegar    |
| `Super + Ctrl + V`           | Administrador del portapapeles    |

En Linux, normalmente necesitás `Ctrl + Shift + C/V` para copiar y pegar en la terminal y `Ctrl + C/V` en todos lados. Estos atajos de portapapeles unificados de Omarchy funcionan en todas partes.

## Captura

| Atajo              | Función                       |
| ------------------- | ------------------------------ |
| `Print Screen`            | Captura de pantalla                      |
| `Super + Shift + S`            | Captura de pantalla (la misma, para teclados sin tecla Print Screen) |
| `Super + Ctrl + C` | Menú de captura |
| `Alt + Print Screen`            | Grabación de pantalla                     |
| `Super + Print Screen` | Selector de color |
| `Super + Ctrl + Print Screen` | Extraer texto al portapapeles |
| `Super + Alt + [` | Achicar la webcam superpuesta mientras grabás |
| `Super + Alt + ]` | Agrandar la webcam superpuesta mientras grabás |
| `Alt + Shift + L` | Copiar la URL actual de una web app o de Chromium |
| `Alt + Shift + D` | Descargar el video de la página actual a `~/Videos` |
| `Super + Ctrl + X` | Empezar/terminar el dictado (requiere _Configurar > Predeterminados > Dictado_) |
| `Right Alt` / `F9` | Dictado mientras mantenés apretado (requiere Voxtype o Superwhisper) |

Para las grabaciones de pantalla, el atajo primero te pregunta qué audio querés y después empieza a grabar. Apretalo otra vez para terminar. Mirá [capturas y grabación](12-screenshots-recording.md) para los detalles.

Todas las opciones de captura también están en _Acciones > Capturar_ en el menú de Omarchy (`Super + Space`).

## Tmux

La tecla prefijo es `Ctrl + Space` (`Ctrl + B` también funciona). Podés cambiar estos atajos en `~/.config/tmux/tmux.conf`.

### Paneles

| Atajo                  | Función              |
| ----------------------- | --------------------- |
| `Prefix + v` | Dividir el panel al costado (vertical) |
| `Prefix + h` | Dividir el panel abajo (horizontal) |
| `Prefix + x` | Cerrar el panel |
| `Prefix + z` | Hacer zoom en el panel (pantalla completa) |
| `Alt + Enter` | Dividir el panel abajo (sin prefijo) |
| `Alt + Shift + Enter` | Dividir el panel al costado (sin prefijo) |
| `Alt + Escape` | Cerrar el panel (sin prefijo) |
| `Ctrl + Alt + Arrows` | Moverse entre paneles |
| `Ctrl + Alt + Shift + Arrows` | Cambiar el tamaño de los paneles |

### Ventanas

| Atajo                  | Función              |
| ----------------------- | --------------------- |
| `Prefix + c` | Ventana nueva |
| `Prefix + k` | Cerrar la ventana |
| `Prefix + r` | Renombrar la ventana |
| `Alt + 1-9` | Ir a una ventana específica |
| `Alt + Arrow Left/Right` | Moverse entre ventanas |
| `Alt + Shift + Arrow Left/Right` | Mover la ventana a la izquierda/derecha |

### Sesiones

| Atajo                  | Función              |
| ----------------------- | --------------------- |
| `Prefix + C` | Sesión nueva |
| `Prefix + K` | Cerrar la sesión |
| `Prefix + R` | Renombrar la sesión |
| `Prefix + N` | Sesión siguiente |
| `Prefix + P` | Sesión anterior |
| `Alt + Arrow Up/Down` | Moverse entre sesiones |
| `Prefix + s` | Listar las sesiones |
| `Prefix + d` | Desconectarse de la sesión |

### Modo copia (estilo vi)

| Atajo                  | Función              |
| ----------------------- | --------------------- |
| `Prefix + [` | Entrar al modo copia |
| `v` | Empezar la selección (en modo copia) |
| `y` | Copiar la selección (en modo copia) |

### General

| Atajo                  | Función              |
| ----------------------- | --------------------- |
| `Prefix + q` | Recargar la configuración |
| `Prefix + ?` | Mostrar los atajos de Tmux |
| `Prefix + :` | Línea de comandos |

### Funciones de distribución de Tmux

Estas funciones se tienen que ejecutar dentro de una sesión de Tmux.

| Comando | Función |
| ------- | -------- |
| `tdl <ai> [<second_ai>]` | Crear una distribución de desarrollo con editor, IA y terminal |
| `tdlm <ai> [<second_ai>]` | Crear una distribución de desarrollo por subcarpeta |
| `tsl <count> <command>` | Crear una distribución de enjambre con varios paneles |
